# Where these logos came from

Each file is the vendor's own artwork, kept exactly as fetched on 2026-11-13. An
integration names its file with `logo=` in its declaration; see
docs/integration-contract.md.

| File | Fetched from | Form |
| --- | --- | --- |
| `unifi.png` | https://ui.com/microsite/apple-touch-icon.png | PNG, 256 x 256 pixels. Ubiquiti publishes this symbol as an image only |
| `nextdns.png` | https://nextdns.io/_next/static/media/logo-icon.cef64c1923c8924d6de76912bcdfe88b.png (the logo in nextdns.io's own stylesheet) | PNG, 450 x 528 pixels. NextDNS publishes its symbol as an image only |
| `proxmox.svg` | https://www.proxmox.com/favicon.svg | SVG symbol |
| `pihole.svg` | https://raw.githubusercontent.com/pi-hole/graphics/master/Vortex/Vortex.svg (the project's official graphics repository) | SVG symbol |

To replace one, fetch the vendor's current file and save it under the same name
without editing it. Product names and logos belong to their owners.
